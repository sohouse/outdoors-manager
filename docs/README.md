# Docs Index

这个目录用于沉淀 Outdoors Manager 的项目知识，而不是替代根目录的 `README.md`。

阅读顺序建议：

1. `README.md`
   仓库总入口，快速了解项目是什么、怎么运行、亮点是什么。
2. `docs/PRODUCT.md`
   项目目标、当前阶段优先级、明确先做什么和暂时不做什么。
3. `docs/ARCHITECTURE.md`
   系统结构、模块职责、关键链路、主要约束与设计取舍。
4. `docs/DEVELOPMENT.md`
   开发约定、代码分层、测试最小要求、修改边界。
5. `docs/ENGINEERING_HANDOFF.md`
   本地运行、验证、交接和排障的最小 runbook。
6. `docs/REMAINING_WORK.md`
   下一阶段工作路线图。

补充材料：

- `docs/interview-notes.md`
  面试讲述材料、3 分钟介绍、demo 路线、深问答案。
- `docs/ts-fullstack-prep.md`
  围绕当前项目整理的 TS/React/Next/API/Auth/Test 高频问法。
- `docs/templates/task-template.md`
  单个非小任务的统一模板。
- `docs/plans/`
  具体方案、拆解和实施记录。

当前文档策略：

- 根目录 `README.md` 面向第一次访问仓库的人。
- `docs/` 面向后续维护、扩展、协作和面试整理。
- 先保证每份文档各司其职，再决定是否继续细拆。
